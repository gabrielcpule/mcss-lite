# Project memory: MCSS-Lite

Working memory for AI sessions on this repo. Read it at the start of a session; update it when a decision is made or the state changes. Newest state first.

## Owner

- **Gabriel Pule**: author of MCSS and MCSS-Lite; product designer focused on AI UX and design systems.
- **Goal for this repo:** a portfolio showcase of a contract-first, AI-ready design system (see `PRODUCT.md`). Real adoption is secondary, but everything must actually work.

## How Gabriel likes to work

- Start creative work with `/brainstorm` (Superpowers brainstorming skill) and quality passes with `/impeccable`. Both are vendored in `.claude/` (see `.claude/VENDORED.md`).
- Wants decisions grounded in research on successful systems (GitLab Pajamas, Primer, Atlassian, Shopify Polaris, shadcn).
- Approves designs section by section; asks for adjustments rather than rewrites.
- Impeccable runs include both `critique` and `audit`.
- Figma support must work for **any** account (native import files + generated push script). Gabriel's own copy lives in the **pule** team: "MCSS-Lite Tokens" (file key `oPGy6RPx7mAhDDK8op1I33`). Never commit account-specific IDs to shipped files.
